# Seredix Smart Calendar

A small, dependency-free calendar app. Open `index.html` in a browser (or run `python3 -m http.server` in this folder).

## Features
- Month view with day selection and today highlight
- Smart quick-add: type `Lunch tomorrow 12:30`, `Dentist friday 9am`, or `Call mom 2026-12-01 18:00`
- Conflict highlighting for events at the same time
- Events stored locally in the browser (localStorage)
- Light/dark theme follows the system
